# 1 Business Scenario 
RavenStack is a B2B SaaS company offering multiple subscription plans and product features. Despite steady customer growth, profitability and retention are uneven. Leadership needs data-driven insights to optimize revenue, product feature adoption, and support operations.

# 2 Objectives
## This project addresses key business questions:
- Which subscription plans generate the highest profits and retention?
- Which product features drive engagement and customer satisfaction versus cost?
- Which customer segments should be prioritized or addressed for retention?
- How can support operations influence churn and profitability?

# 3 Dataset
## The project uses a multi-table SaaS dataset sourced from Kaggle:

| Table           | Rows   | Description                        |
|-----------------|--------|------------------------------------|
| accounts        | 500    | Customer entities and attributes   |
| subscriptions   | 5,000  | Subscription history and plan info |
| feature_usage   | 25,000 | Feature-level usage events         |
| support_tickets | 2,000  | Tickets, severity, resolution time |
| churn_events    | 600    | Churn events with reasons          |
